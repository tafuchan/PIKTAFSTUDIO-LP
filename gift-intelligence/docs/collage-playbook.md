# コラージュ作成プレイブック（Claude / Codex のブラウザ代行操作用）

Amazonアソシエイトの「コラージュ」機能で、TikTokのギフトまとめ投稿風の
商品コラージュを作り、ストアフロントに載せるための手順書。
AIエージェント（Claude / Codex CLI）がブラウザを代行操作する前提で書く。

## 原則（毎回must）

1. **ログインは人間が行う**。エージェントはログイン済みのブラウザを引き継ぐだけ。
   パスワード入力・CAPTCHA対応はしない。
2. **公開しない**。作成は「下書き保存」まで。公開ボタンは人間が確認して押す
   （予約投稿の設定もしない）。
3. **画像を持ち出さない**。コラージュ画面の商品画像をスクショ・保存して
   外部サイトで使うのは規約違反（アカウント停止リスク）。コラージュの成果物は
   Amazonストアフロント上でのみ公開する。
4. 1セッションで作るのは2〜3件まで。機械的な大量作成をしない。

## 入力（事前に用意するもの）

`node scripts/export-collage.js` が生成する設計図
（`reports/collage/<context>.md`）。内容:
- 見出しテキスト案
- 掲載商品リスト（GiftScore順、コラージュ内検索用キーワード付き）

## 操作手順

1. 人間: https://affiliate.amazon.co.jp にログインした状態でエージェントを呼ぶ
2. 右側メニュー →「ストアフロント」→「コンテンツを管理する」
3. 「コンテンツを作成」→「コラージュ」
4. テンプレートを選ぶ（TikTok風のギフトまとめに寄せるなら、
   商品を格子状に4〜6点並べられる縦長テンプレを優先）
5. 見出しテキストを設計図の「見出しテキスト案」から設定
6. 「商品」タブ → 「＋」→ 検索ボックスに設計図の
   「コラージュ内検索キーワード」を貼って検索 → 該当商品にチェック → 完了
   - 検索で見つからない場合: ブランド名のみで再検索 → それでも無ければ
     その商品はスキップして設計図の次点商品を使う
   - **別商品を妥協で選ばない**（設計図と同一と確信できるもののみ）
7. ドラッグ&ドロップで配置を整える（rank順に左上→右下）
8. 「プレビュー」→「保存する」で**下書き保存**（送信しない）
9. 作成したコラージュのタイトル・使用商品・スキップした商品を報告する

## Codex CLIから実行する場合

Codexは自前のブラウザ操作を持たないため、Playwright等を使う場合も
上記の原則1〜4をプロンプトに必ず含めること。呼び出し例:

```bash
codex exec --dangerously-bypass-approvals-and-sandbox --skip-git-repo-check \
  -C "<gift-intelligenceのパス>" \
  "reports/collage/<context>.md の設計図に従い、ログイン済みブラウザで
   アソシエイト・セントラルのコラージュを下書き保存まで作成。
   公開禁止・画像持ち出し禁止・ログイン操作禁止。結果を報告。"
```
